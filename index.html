Featured projects

Nimbus

RAG · full-stack · live

An AI workplace assistant for companies that also onboards new hires. Employees log in and ask questions about the company, and the assistant answers only from the documents their role is allowed to see. Every answer cites its sources, and it refuses instead of guessing.

  • Login with role-based access: each employee sees company-wide docs, their department's docs and their own personal files, nothing else
  • Two retrieval routes: hybrid search (pgvector + Postgres full-text, merged with Reciprocal Rank Fusion) and an agentic file search using list_folder, grep and read_file tools
  • Access control enforced in the retrieval layer (SQL filters and permission-gated tools), not left to the LLM
  • Tested with a 32-question evaluation set, including access "traps", multi-hop and unanswerable questions

Newscaster AI

AI workflow · deployed, runs daily

A personal AI news workflow. Every morning it scrapes trusted AI and ML blogs, extracts the full articles, has an LLM read them like an editor (story type, angle, key insight), and emails a grouped digest.

  • Pipeline with a status state machine per article: fetched → content_fetched → analyzed → emailed
  • Runs on a GitHub Actions schedule against Supabase Postgres, at zero hosting cost
  • Schema managed with Alembic migrations; duplicate-safe inserts
